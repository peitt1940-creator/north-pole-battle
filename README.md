# 北極16宮格攻防戰

國小資優班聖誕遊戲：老師投影 4×4 棋盤，紅、綠、金三組各使用一台平板，同時提交兩項行動；封存後等待老師統一揭曉。六回合，第 2、4、6 回合抽搞笑籤。

## 專案狀態
- 已建立全新 GitHub 儲存庫，避免覆蓋其他教學遊戲。
- Firebase 尚未連接，GitHub Pages 尚未啟用；目前不能進行四台平板即時測試。
- 第一版原型需補強資料庫權限規則，尤其**未揭曉的指令不可被其他組讀取**、提交後必須由伺服器拒絕修改，以及結算操作需防止重複執行。
- 完成 Firebase 專案設定後再發布可供學生操作的版本。

## 規則
每隊每回合提交兩項不同格子的行動：占領空格、進攻敵格、防守己格。三組同步封存，教師統一揭曉，按防守→進攻→占領結算。兩隊爭同一空格，該格不被占領。

## 安全規範
此儲存庫只允許程式碼、虛構遊戲資料與公開美術素材。不得上傳學生姓名、成績、輔導紀錄、個資、密碼、服務帳戶金鑰。Firebase Web config 可公開，但必須以 Authentication 和 Database Rules 實施權限控管。
